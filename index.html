Selamat Datang di E-Penilaian

Aplikasi ini dirancang untuk memudahkan guru dalam melakukan penilaian formatif dan sumatif secara kolektif. Data dapat disimpan secara lokal atau dihubungkan ke Google Spreadsheet.

Petunjuk Penggunaan:

  1. Masuk ke menu Data Siswa untuk menambahkan daftar murid.
  2. Buka menu Input Nilai untuk memasukkan nilai secara kolektif (UH, TH, US).
  3. Lihat hasil akhir dan predikat pada menu Rekapan Nilai.
  4. Ke menu Pengaturan untuk menghubungkan aplikasi ke Google Sheets.

Koneksi Google Sheets (Database)

Secara default, data disimpan di browser (Local Storage). Untuk menyimpan data di Google Sheets agar aman dan bisa diakses dari perangkat lain, masukkan URL Web App Google Apps Script Anda.

Cara Setup Google Sheets (Format Tabel Rapi):

  1. Buat Google Spreadsheet baru (atau gunakan yang sudah ada, data lama di sheet pertama abaikan saja).
  2. Buka menu Ekstensi > Apps Script.
  3. Hapus semua kode lama, lalu Salin dan tempel kode Apps Script BARU di bawah ini.
  4. Simpan, lalu klik Terapkan (Deploy) > Deployment baru. (Jangan pilih kelola deployment untuk memastikan URL baru aktif dengan benar).
  5. Pilih jenis Aplikasi Web. Deskripsi: "API Penilaian V2".
  6. Jalankan sebagai: Saya. Yang memiliki akses: Siapa saja (Anyone).
  7. Klik Terapkan, salin URL Aplikasi Web yang baru, dan paste di kolom atas.

Penting: Kode baru ini akan memisahkan data secara otomatis ke dalam sheet "Siswa", "Pelajaran", "Nilai", dan "Pengaturan" agar mudah dibaca seperti tabel biasa.

Kode Apps Script Baru: 
// === PASTE KODE INI DI GOOGLE APPS SCRIPT ===

function doPost(e) {
  try {
    if (!e || !e.postData || !e.postData.contents) return createResponse({ status: 'error', message: 'Tidak ada data.' });
    var data = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    if (!ss) return createResponse({ status: 'error', message: 'Spreadsheet tidak ditemukan.' });

    var shStudents = ss.getSheetByName('Siswa') || ss.insertSheet('Siswa');
    shStudents.clear();
    var studentRows = [['ID', 'NIS/NISN', 'Nama Lengkap', 'Gender']];
    if (data.students && data.students.length > 0) data.students.forEach(function(s) { studentRows.push([s.id, s.nis, s.name, s.gender]); });
    shStudents.getRange(1, 1, studentRows.length, studentRows[0].length).setValues(studentRows);
    
    var shSubjects = ss.getSheetByName('Pelajaran') || ss.insertSheet('Pelajaran');
    shSubjects.clear();
    var subjectRows = [['ID', 'Nama Mata Pelajaran', 'Capaian Pembelajaran']];
    if (data.subjects && data.subjects.length > 0) data.subjects.forEach(function(s) { subjectRows.push([s.id, s.name, s.target]); });
    shSubjects.getRange(1, 1, subjectRows.length, subjectRows[0].length).setValues(subjectRows);

    var shGrades = ss.getSheetByName('Nilai') || ss.insertSheet('Nilai');
    shGrades.clear();
    var gradeRows = [['ID Mapel', 'ID Siswa', 'Tipe Nilai', 'Nilai 1', 'Nilai 2', 'Nilai 3', 'Nilai 4', 'Nilai 5', 'Nilai 6', 'Nilai 7', 'Nilai 8', 'Nilai 9', 'Nilai 10']];
    if (data.grades) {
        for (var mapelId in data.grades) {
            for (var tipe in data.grades[mapelId]) {
                for (var siswaId in data.grades[mapelId][tipe]) {
                    var val = data.grades[mapelId][tipe][siswaId];
                    var row = [mapelId, siswaId, tipe.toUpperCase()];
                    if (tipe === 'us') { row.push(val !== undefined ? val : ''); while(row.length < 13) row.push('');
                    } else { if (Array.isArray(val)) { for(var i=0; i<10; i++) { row.push(val[i] !== undefined && val[i] !== '' ? val[i] : ''); }
                    } else { while(row.length < 13) row.push(''); } }
                    gradeRows.push(row);
                }
            }
        }
    }
    shGrades.getRange(1, 1, gradeRows.length, gradeRows[0].length).setValues(gradeRows);
    
    var shSettings = ss.getSheetByName('Pengaturan') || ss.insertSheet('Pengaturan');
    shSettings.clear();
    var settingsRows = [['Pengaturan', 'Nilai'],['uhCount', data.settings ? data.settings.uhCount : 4],['thCount', data.settings ? data.settings.thCount : 4],['gasUrl', data.settings ? data.settings.gasUrl : '']];
    shSettings.getRange(1, 1, settingsRows.length, settingsRows[0].length).setValues(settingsRows);
    return createResponse({ status: 'success', message: 'Data berhasil disimpan.' });
  } catch (error) { return createResponse({ status: 'error', message: error.toString() }); }
}
